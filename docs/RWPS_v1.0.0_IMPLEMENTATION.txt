UNTILL INTEGRATED INTO rwps.cron OR EQUIVALENT
To retrieve forcing for a particular data and cycle and setup forcing for an rwps mesh:
 >> cd ../ush
 >>  ./prepare_forcing.sh $PDY $cyc $meshID
e.g.
 >>  ./prepare_forcing.sh 20261123 00 oc_1500m_30km
when proceesses launched by  prepare_forcing.sh are finished, execute waveprnc for 
current, ice, waterlevel and wind:
 >> ./rwps_prnc  20261123 00 oc_1500m_30km
This script will create ww3 format binary forcing files:
current.ww3, ice.ww3, level.ww3 and wind.ww3 in directory

DATA=/lfs/h2/emc/ptmp/${USER}/rwps/v1.0.0/JRWPS_PREP/tmp

and also copy mesh specific mod_def.ww3 file to DATA.
